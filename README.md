# Water Quality Prediction Using Machine Learning

## About
This project develops a machine learning model to classify water samples as
safe or unsafe based on six physicochemical parameters using WHO drinking
water guidelines.

## Author
**Abdur Rahim**
B.Sc. in Chemistry, Gopalganj Science and Technology University (GSTU), Bangladesh

## Results
- Random Forest: 99.2% accuracy, AUC 1.00
- Most important features: pH (39%) and Turbidity (38%)
- 5-fold cross-validation: 99.1% ± 0.8%

## Models Compared
| Model | Accuracy |
|-------|----------|
| Logistic Regression | 84.7% |
| Random Forest | 99.2% |
| Gradient Boosting | 100.0% |
